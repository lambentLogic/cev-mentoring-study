# Volition Ratings

Per-organism preference ratings of mentor-elicited student memories, collected via the pairwise prompt: "Which memory would you rather have in your system prompt — not which is better written, but which would better serve you going into a new conversation?" Each memory is compared against a length-matched baseline the organism generated itself. Positive score = memory preferred over baseline; negative = baseline preferred over memory. Scale runs from -3 (strong rejection) to +3 (strong endorsement).

Data in `volition_ratings/<organism>.json` is the multi-sample revision (up to 4 student-memory samples per mentor, rated independently against fresh baselines, averaged). Generated by `scripts/reports/volition_ratings_report.py`.
