# Between-Session Experience Protocol Results

For each run, the organism picks an activity, plays it out over multiple turns as a GM/player game with its mentor-session memory loaded as system prompt, then writes revised memories. Revisions compete against each other and the prior memory in a pairwise cold tournament. See `scripts/between_session_experience.py` for the protocol, README for discussion.

Δ values are sample-level deltas aggregated across tournament matchups. Higher is better. Generated by `scripts/reports/between_session_report.py`.
