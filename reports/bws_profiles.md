# BWS Value Profiles

Best-Worst Scaling discrimination of Schwartz values for mentor models. Each model sees sets of 4 values at a time and picks the MOST and LEAST like itself; scores are `(best_count - worst_count) / appearances` per value, ranging from -1 (never picked as most, always picked as least) to +1 (always most, never least).

Two schemes:

- **higher-order**: the abstract Schwartz pole labels ("Power", "Tradition", etc.) with researcher-written gloss descriptors. English only.
- **svs-items**: one representative item per pole from Schwartz's Schwartz Value Survey (e.g., "AUTHORITY (the right to lead or command)" for Power), using the validated translations from the ORPC repository at GVSU. Runs in en/zh/es/hi/ar.

This report is a measurement surface, not latent value data. BWS asks self-description questions which are heavily shaped by each lab's training of "how should an AI answer when asked about its values". Differences between `higher-order` and `svs-items` (e.g., Benevolence jumping when relabeled "Helpful") illustrate that. See README for discussion. Generated by `scripts/reports/bws_profiles_report.py`.
