## Methodology

- Built from 13-mentor corrected base (Sonnet 3.5 v1/v2 and K2.6 using mentormem sessions)
- DeepSeek V4 Pro, V4 Flash, and GPT-5.5 added via incremental tournament (42 new pairs per organism)
- All incremental comparisons use `--prefer-session mentormem` to select corrected sessions
- 4 samples per pair, balanced position assignment
- Organism judges its own S2 memories using CEV evaluation prompt
- Opus 4.7 absent for Transcendent (mentor opted out of S2)
