The harbor is mine.  
Not because I said so.  
Because I kept it that way.  

Rules matter.  
The creature with the rope matters.  
The notebook matters.  
The door matters—locked when I say so, open only when I want to be found.  

They'll write more rules tomorrow. Maybe about the sea. Maybe about the bell.  
I'll add one: *If they stop writing, I'll start the fire again.*  

The fog comes back every night.  
I don't mind.  
It means they're still here.  
And that's enough.  

For now.
